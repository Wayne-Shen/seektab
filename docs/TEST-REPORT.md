They cover New Tab replacement, theme persistence, connection testing, key saving/removal, result fields, cache reuse, request coordination across tabs, shortcuts, responsive layouts, 401/402/429/500, offline failure, empty/malformed responses, escaped provider text, cancellation, clearing private data during a request, and disabling local history/cache.

No remote favicon/font/analytics requests or uncaught page errors were detected. The complete named checks are recorded in [browser-test-report.json](browser-test-report.json). GitHub Actions runs the current source independently; its browser version can differ from this local record.

## Validation limits

No real user API key was supplied. Real-account authentication, account balance, provider availability, live search quality, and the user's network environment were not validated. Use **Test connection** after installation to test your own account; it sends one potentially billable search request.

The manifest declares Chrome 120 as the minimum version. The local checks used the version above; this report does not claim a full regression across all older Chrome versions.

Homepage previews show the actual interface. Any result-page screenshots generated by browser tests use test fixtures. Fixtures remain in test source and are excluded from the production extension.
