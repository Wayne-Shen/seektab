Patch release for SeekTab. The extension code is unchanged from v1.0.0; this release republishes the package with the manifest version bumped and adds automated release publishing.

## Changes

- Added a GitHub Actions release workflow that verifies the build, packages the extension and source, runs the browser checks, and publishes the ZIP archives plus `SHA256SUMS.txt` as a GitHub Release.
- Added repository agent instructions (`AGENTS.md`, `agent.md`), a development handoff (`HANDOFF.md`) and a research and design document for the DeepSeek Search / Fetch API integration.
- Packaging now excludes the ignored local migration record from the source archive.

## Install

Download **SeekTab-1.0.1-unpacked.zip**, extract it, open `chrome://extensions`, enable Developer mode, and choose **Load unpacked** → `SeekTab-unpacked`.

Open a new tab, enter your own DeepSeek API key in Settings, test the connection, and save. The extension UI currently uses Simplified Chinese. Connection testing makes one real search request and may incur API charges.

## Downloads

- `SeekTab-1.0.1-unpacked.zip` — prebuilt extension, ready to load.
- `SeekTab-1.0.1-source.zip` — complete source with bilingual documentation, tests, and packaging scripts.
- `SHA256SUMS.txt` — checksums for both ZIPs.

Local validation before publishing: formatting check, 17 core tests, and the real-extension browser checks with mocked API responses. No live user API key was supplied, so real-account authentication and live result quality still require installation-time verification.

See the [README](https://github.com/Wayne-Shen/seektab#readme) for permissions, local key storage, installation, and build instructions, and the [Simplified Chinese README](https://github.com/Wayne-Shen/seektab/blob/main/README_CN.md) for the Chinese version.
