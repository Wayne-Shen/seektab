Documentation patch release for SeekTab. The extension code is identical to v1.0.1; this release republishes the package with the manifest version bumped and the development documentation updated.

## Changes

- Documented the contributor and agent workflow in `AGENTS.md`, `agent.md` and `HANDOFF.md`, with navigation links from both READMEs.
- Added the DeepSeek Search / Fetch API research and design draft under `docs/`. It is a proposal only: no Fetch, AI summary or service-worker changes are implemented.
- Recorded how releases are produced and the current limitation of the GitHub token used here.

## Install

Download **SeekTab-1.0.2-unpacked.zip**, extract it, open `chrome://extensions`, enable Developer mode, and choose **Load unpacked** → `SeekTab-unpacked`.

Open a new tab, enter your own DeepSeek API key in Settings, test the connection, and save. The extension UI currently uses Simplified Chinese. Connection testing makes one real search request and may incur API charges.

## Downloads

- `SeekTab-1.0.2-unpacked.zip` — prebuilt extension, ready to load.
- `SeekTab-1.0.2-source.zip` — complete source with bilingual documentation, tests, and packaging scripts.
- `SHA256SUMS.txt` — checksums for both ZIPs.

The archives in this release were built by the repository CI workflow on Node 24 and verified with `shasum -a 256 -c`. Local validation before publishing: formatting check, 17 core tests, and the real-extension browser checks with mocked API responses. No live user API key was supplied, so real-account authentication and live result quality still require installation-time verification.

See the [README](https://github.com/Wayne-Shen/seektab#readme) for permissions, local key storage, installation, and build instructions, and the [Simplified Chinese README](https://github.com/Wayne-Shen/seektab/blob/main/README_CN.md) for the Chinese version.
