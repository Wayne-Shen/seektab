# SeekTab 1.1.0

A search-first new tab using Material 3 Expressive styling: a single rounded search field, quieter typography, tonal light/dark surfaces, and concise Chinese labels.

- Removed home-page slogans, date, shortcut grid, recent-search chips, and footer copy.
- Kept history one click away; moved theme selection and existing shortcuts into Settings.
- Simplified results into one column with source, title, snippet, optional date, and refresh/cancel actions.
- Preserved storage format, saved preferences, key handling, cache behavior, request coordination, permissions, and CSP.
- Added coverage for preserved saved state and Settings drafts during shortcut editing.

## Update without changing your local extension ID

Back up the current unpacked extension folder. Extract this release separately, verify SHA256SUMS.txt, and replace the files inside your existing installation directory at the same path. Click Reload on the existing entry in chrome://extensions and compare its ID. Do not uninstall or load a second folder. Existing Chrome local storage remains attached to the original extension ID.

The extension ZIP, source ZIP, and checksums are built by the repository's GitHub Actions CI workflow. Browser tests use mocked provider traffic; no live API calls are made. A saved key is never included in these packages.
