# SeekTab 1.2.0

Search settings now support site and language filters, date bounds, exact phrases, excluded terms, 1–50 results, optional provider summaries and scores, manually supplied localization IPv4, and optional page content. The original question accompanies filter-expanded queries.

Advanced requests bypass the result cache; page content is shown as plain text, limited to 12,000 characters per result, and is not cached. Optional IP addresses are sent only when explicitly configured. Scores are provider estimates, not factual verification. Existing storage and extension permissions are retained.

Search and connection tests can be billable. For an existing unpacked installation, back up the folder, replace its files at the same path and reload the existing entry to preserve its extension ID and settings.
