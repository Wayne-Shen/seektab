# SeekTab 1.3.0

查看 DeepSeek 账户余额和本机 SeekTab Search 请求报表。

- 新增手动刷新报表：展示余额、刷新截止时间、统计起点、请求汇总和按日报表。
- 只有点击「刷新」才会查询官方余额接口并更新报表快照；打开报表不会发起余额请求。
- 请求统计仅涵盖本机扩展在启用本功能后完成的 Search 请求，包括连接测试和曾使用的 API Key；不含缓存命中或其他应用。按日汇总不保存搜索词或密钥，也不代表 DeepSeek 官方账单。
- 保留原有扩展权限和设置；历史账单及真实收费情况请以 DeepSeek 平台为准。
- 记录功能完成后提交 GitHub、运行 Actions 并发布新版本的项目工作流程。

## 更新现有扩展

备份当前解压目录，将此版本文件替换到同一路径后，在 Chrome 扩展页面重新加载已有条目。不要卸载或加载另一个目录，以保留扩展 ID 和本地设置。

扩展包、源码包与校验文件由 GitHub Actions 构建。自动化测试使用模拟 API，不产生真实调用。
