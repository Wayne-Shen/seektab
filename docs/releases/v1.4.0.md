# SeekTab 1.4.0

全新的 Command 风格新标签页，加上本机标签页 / 书签 / 历史搜索和可选的 AI 回答。

- 新首页：提示符搜索栏、搜索范围（全部 / 标签页 / 书签 / 历史 / 网页 / AI）、右侧时钟与快捷链接（⌥1–⌥9）、四种强调色、12 / 24 小时制。
- 本机搜索：输入时在本机匹配已打开的标签页、书签和 Chrome 浏览历史；回车切换到标签页或打开链接。这些内容不会上传，也不会被保存副本，可在设置中分别关闭。
- AI 回答（可选，仅在你主动点击时触发）：基于已有搜索结果调用一次流式 `/responses`（默认 `deepseek-flash`），回答带有可点击的编号引用，不存在的引用会被移除；回答只保留在当前页面。每次包含一次搜索和一次模型调用，可能计费；设置中有本机每日上限、模型、结果数和长度。
- 网页结果可按相关度或日期排序；新增「重置」按钮清除当前搜索。
- 界面支持中文 / English，右栏可一键切换语言与浅色 / 深色主题；快捷链接显示来自 Chrome 本地缓存的网站图标（不发起网络请求）。
- **权限变化**：新增 `tabs`、`bookmarks`、`history`、`favicon`，仅用于上述本机功能。其余限制不变：无后端、无统计、无内容脚本，API Key 仍只存于本机。

## 更新现有扩展

备份当前解压目录，将此版本文件替换到同一路径后，在 Chrome 扩展页面重新加载已有条目，并接受新增权限。不要卸载或加载另一个目录，以保留扩展 ID 和本地设置。

扩展包、源码包与校验文件由 GitHub Actions 构建。自动化测试使用模拟 API，不产生真实调用；AI 回答已由维护者用自己的 Key 做过一次手动验证。
