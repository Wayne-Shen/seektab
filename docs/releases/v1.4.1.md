# SeekTab 1.4.1

修复部分网站无法从快捷链接打开的问题。

- 快捷链接、搜索结果、⌥1–⌥9 快捷键和命令面板现在通过 `chrome.tabs` 打开链接，行为与在地址栏输入网址一致。此前从扩展页面发起的跨站跳转会被某些网站（例如校验请求来源的 LuCI 路由器管理页）拒绝。
- 按住 Ctrl / ⌘ / Shift / Alt 点击或中键点击仍使用浏览器默认行为。
- 权限、数据与隐私无变化。

## 更新现有扩展

备份当前解压目录，将此版本文件替换到同一路径后，在 Chrome 扩展页面重新加载已有条目。不要卸载或加载另一个目录，以保留扩展 ID 和本地设置。

扩展包、源码包与校验文件由 GitHub Actions 构建。
